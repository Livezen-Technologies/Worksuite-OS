# WorkSuite logo (source)

`worksuite-logo-dark.png` / `worksuite-logo-light.png`: the official worksuite wordmark (350 × 90, as supplied).
The vendor logos one level up are made from the dark one (for the dark sign-in screen): its background keyed out,
then the "OS" tag (IBM Plex Sans SemiBold, white on #1F6BFF) set beside it at 64, 128 and 256 px high
(`logo-text-*`, and `logo-text-version-*` with the version). The mark alone (`logo.svg`) is the same geometry as
the loader's assembled frame, as a vector. The 128 and 256 px versions are scaled up from the 90 px source: a vector
original of the wordmark would make them sharp.
